# Potato 习惯模块设计方案 v1.0

> 已确认的前提
> - 习惯是独立底部 Tab：专注 / 习惯 / 数据 / 设置
> - 第一版支持：**计时型习惯**、**次数/计量型习惯**
> - 频率：每天 / 自选星期
> - 完成规则：当天累计达标；允许手动补完成
> - 计时型习惯点击开始后进入专注页，按目标时长跑单次倒计时
> - 提醒按早上 / 下午 / 晚上汇总，每个时段每天最多一条
> - 不做惩罚式连续记录

---

## 1. 产品定位

习惯模块回答两个问题：

1. **今天有哪些习惯要做？**
2. **每个习惯需要投入多少时间或次数？**

它不负责复杂的项目管理，也不做第二个任务列表。
习惯是「每天重复的节奏」，专注计时器负责实际执行，数据页负责复盘。

核心闭环：

> 设定习惯 → 到时段汇总提醒 → 开始计时 / 记录次数 → 完成后打卡 → 查看连续天数与累计投入

---

## 2. 信息架构

底部 4 个 Tab：

```
专注        习惯        数据        设置
```

- 专注：番茄钟、正计时、习惯计时运行页
- 习惯：今日习惯、历史、新增/编辑
- 数据：整体专注数据 + 习惯完成度
- 设置：提醒时段、每日常规设置、数据导出

---

## 3. 习惯类型

### 3.1 计时型

字段：

- 名称：阅读
- 目标时长：30 分钟（1–180）
- 频率：每天 / 自选星期
- 提醒时段：早上 / 下午 / 晚上 / 不提醒
- 提示语：可选，例如「读专业书」

完成规则：

- 当天所有关联该习惯的专注时长累计达到目标分钟 → 自动完成
- 可多次开始，时长累加
- 允许手动补完成，但记录标记为「手动完成」
- 提前结束保留实际分钟，不抹掉

### 3.2 次数 / 计量型

字段：

- 名称：喝水
- 目标次数：8
- 单位：杯 / 次 / 组 / 页
- 每次步进：+1（v1 固定）
- 频率和提醒同上

完成规则：

- 点击 +1 增加进度
- 达到目标次数 → 自动完成
- 支持撤销一次误点
- 当天进度保留

> v1 不强制「必须一次完成」；所有类型都允许分多次累计。

## 4. 习惯页

### 4.1 今日视图

```
┌──────────────────────────────┐
│ 习惯                          │
│ 11月5日 · 周四       2 / 4    │
│ ███████████░░░░  50%          │
│                              │
│ 早上                   08:30 │
│ 📖 阅读 30 分钟   连续 6 天   │
│                   [ 开始 ] ○  │
│ 🧘 冥想 10 分钟   连续 2 天   │
│                   [ 开始 ] ○  │
│                              │
│ 下午                   14:00 │
│ 💧 喝水 3 / 8 杯              │
│                        [ +1 ] │
│                              │
│ 晚上                   20:30 │
│ ✍️ 写日记 15 分钟             │
│                   [ 开始 ] ✓  │
│                              │
│ + 添加习惯                    │
└──────────────────────────────┘
```

- 按时段分组，组头显示该时段的提醒时间
- 计时型：未开始显示「开始」，进行中显示「返回计时」，已完成显示勾选
- 次数型：显示进度和 +1 按钮
- 已完成的习惯下沉到「已完成」，减少干扰
- 顶部只展示今日完成度，不展示负罪文案
- 无提醒的习惯单独归入「未安排时间」

### 4.2 习惯卡片状态

| 状态 | 表现 |
|---|---|
| 未开始 | 图标、名称、目标时长/次数、连续天数、开始按钮 |
| 计时中 | 显示「进行中 · 剩余 12:30」；点击回到专注页 |
| 次数进行中 | 显示 `3 / 8 杯`，带 +1 和撤销 |
| 已完成 | 弱化卡片，显示完成时间与「已完成」 |
| 今天跳过 | 显示「今天休息」，不显示失败 |
| 暂停 | 不出现在今日清单，历史保留 |

### 4.3 新增 / 编辑习惯

使用底部抽屉或独立页面，字段按类型变化：

```
名称        [ 阅读                     ]
类型        [ 计时型 ]  [ 次数/计量型 ]
目标        [ 30 ] 分钟    或 [ 8 ] [杯]
频率        [ 每天 ] [一][二][三][四][五][六][日]
提醒时段    [ 早上 ] [ 下午 ] [ 晚上 ] [ 不提醒 ]
图标/颜色   [ 📖 ] [ 珊瑚 / 绿色 / 琥珀 / 蓝色 ]
备注        [ 读专业书                  ]
```

保存后立即回到习惯页；如果今天属于计划日，新习惯立即出现。

### 4.4 习惯详情

点击卡片进入详情：

- 本月完成热力图
- 当前连续天数 / 最佳连续天数
- 完成率
- 累计投入时间或次数
- 最近记录
- 编辑 / 今天跳过 / 暂停习惯 / 删除

删除习惯默认只删除配置，历史记录保留并标注「已删除习惯」；提供「同时删除历史」的二次确认。

## 5. 计时联动

### 5.1 计时型习惯

点击「开始」：

1. 如果当前已有运行中的计时：
   - 提示「当前有一个计时正在进行」，可选择结束它或返回
2. 跳转到专注页，进入「习惯模式」
3. 顶部显示：`习惯 · 阅读`
4. 计时器按目标时长倒计时，例如 30:00
5. 倒计时结束：
   - 记录一条关联习惯的 Session
   - 自动把该习惯今日累计时间加上
   - 若达到目标 → 完成打卡
   - 显示轻量完成提示
6. 提前结束：
   - 记录实际专注分钟
   - 今日累计仍保留
   - 习惯保持未完成，可再次开始或手动补完成

### 5.2 习惯模式与番茄钟的区别

- 习惯模式是**单次倒计时**，不插入短休/长休
- 不增加番茄颗数
- 专注分钟正常计入数据页
- Session 记录 `mode = HABIT`，带 `habitId`
- 完成提示文案：「今天的阅读，完成了。」

### 5.3 次数型习惯

- 不启动专注计时
- 在习惯页点击 +1
- 达到目标时播放轻量完成触感
- 可撤销上一次 +1

### 5.4 从通知进入

汇总通知点击后打开习惯页，由用户选择具体习惯开始；
不在通知里直接启动某个习惯的计时，避免误触。

## 6. 提醒系统

### 6.1 时段

默认三个时段：

| 时段 | 默认时间 |
|---|---|
| 早上 | 08:30 |
| 下午 | 14:00 |
| 晚上 | 20:30 |

用户可在「设置 → 习惯提醒」中修改每个时段的提醒时间，或关闭某个时段。

### 6.2 汇总规则

到了时段提醒时间：

1. 找出今天计划内、属于该时段、尚未完成的习惯
2. 如果为空：不发通知
3. 如果不为空：发一条汇总通知

示例：

> **早上还有 2 个习惯**
> 阅读 30 分钟 · 冥想 10 分钟
> [ 查看习惯 ]

- 每个时段每天最多一条
- 不做追加提醒
- 通知不提供单个习惯操作，避免通知过载
- 完成后不回撤已经发出的汇总通知
- 点击通知 → 打开习惯 Tab

### 6.3 权限与可靠性

- Android 13+ 通知权限
- Android 12+ 精确闹钟权限；没有权限时降级
- AlarmManager 按天排程
- BootReceiver 重启后重新排程
- 时区 / 日期变化时重新计算
- 修改提醒时间、暂停习惯、删除习惯时取消旧排程
- 免打扰时段默认 22:00–08:00；习惯计时结束通知不受影响

---

## 7. 完成与连续天数规则

### 7.1 计时型

- 当日累计专注秒数 ≥ 目标秒数 → 完成
- 手动补完成也计入当天完成，但记录 `source = manual`
- 手动完成不伪造专注分钟

### 7.2 次数型

- 当日累计次数 ≥ 目标次数 → 完成
- 允许撤销误点，撤销后若低于目标则回到未完成

### 7.3 连续天数

- 每个习惯独立计算，不要求当天全部习惯完成
- 只统计计划日
- 今天尚未完成时，不提前断签
- 计划日结束仍未完成 → 连续归零
- 「今天跳过」：不计入连续，也不打断连续（休息日保护）
- 同一天完成后撤销：当天不计数
- 不出现「连续记录毁了」等惩罚文案

### 7.4 日界线

- 使用本地时间午夜换天
- 后续可增加「凌晨 4 点换日」设置
- 跨午夜的习惯计时按 Session 开始日期归属，并允许手动修正

## 8. 数据模型

```sql
CREATE TABLE habits (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  icon TEXT NOT NULL DEFAULT '',
  color TEXT NOT NULL DEFAULT '',
  type TEXT NOT NULL,                  -- TIMED / COUNT
  target_seconds INTEGER NOT NULL DEFAULT 0,
  target_count INTEGER NOT NULL DEFAULT 0,
  unit TEXT NOT NULL DEFAULT '',
  weekdays_mask INTEGER NOT NULL DEFAULT 127, -- 周一..周日
  reminder_slot TEXT NOT NULL DEFAULT 'NONE', -- MORNING/AFTERNOON/EVENING/NONE
  reminder_enabled INTEGER NOT NULL DEFAULT 1,
  note TEXT NOT NULL DEFAULT '',
  sort_order INTEGER NOT NULL DEFAULT 0,
  archived_at INTEGER,
  created_at INTEGER NOT NULL
);

CREATE TABLE habit_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  habit_id INTEGER NOT NULL,
  date TEXT NOT NULL,                  -- YYYY-MM-DD 本地日期
  status TEXT NOT NULL,                -- COMPLETED / SKIPPED / PENDING
  focused_seconds INTEGER NOT NULL DEFAULT 0,
  count_value INTEGER NOT NULL DEFAULT 0,
  source TEXT NOT NULL DEFAULT 'timer',
  completed_at INTEGER,
  note TEXT NOT NULL DEFAULT ''
);
CREATE UNIQUE INDEX idx_habit_log_date ON habit_logs(habit_id, date);

ALTER TABLE sessions ADD COLUMN habit_id INTEGER;
```

- `sessions.habit_id` 关联计时型习惯的历史投入
- 习惯完成时写入/更新 `habit_logs`
- 历史删除习惯后保留 log 与 session
- 数据库版本从 1 → 2，做迁移，不清空现有记录

## 9. 数据页扩展

在现有数据页增加一个「习惯」区块：

- 今日完成度：`3 / 5`
- 本月习惯完成率
- 习惯投入总时间
- 当前最佳连续
- 每个习惯的 30 天热力图
- 点击习惯 → 习惯详情

不把习惯统计拆成第二个数据页，保持整体时间视角。

## 10. 视觉与交互

- 复用现有 Potato 色板、字体、卡片圆角
- 每个习惯可选颜色：珊瑚、鼠尾草、琥珀、蓝灰
- 习惯图标用 Material 图标或首字母
- 完成动效：进度环合拢 + 轻触感，不长篇庆祝
- 次数型 +1 有轻触感，快速连点不重复动画
- 空状态：「今天想养成什么习惯？」
- 不做花园、枯树、排行榜等强游戏化机制

## 11. 边界情况

| 情况 | 处理 |
|---|---|
| 已有计时正在运行 | 阻止再开始习惯计时，提示先结束当前计时 |
| 计时中切到习惯页 | 卡片显示「进行中」，点击回专注页 |
| 计时中修改目标时长 | 只影响下一次计时，本次不变 |
| 删掉正在计时的习惯 | 先阻止删除，提示结束计时 |
| 当天已完成后再次开始 | 允许，但不再重复打卡，时长继续累计 |
| 修改星期后今天不再是计划日 | 当天记录保留，今日列表隐藏，明天按新计划执行 |
| 手动补完成计时型习惯 | 允许，标记手动，不增加专注分钟 |
| 次数型误点 | 支持撤销一次 |
| 通知权限关闭 | 习惯页显示提示，不阻塞使用 |
| 重启设备 | 重新排程所有习惯时段提醒 |

## 12. 实现顺序

1. 数据迁移：habits、habit_logs、sessions.habit_id
2. 习惯 Tab：今日清单、时段分组、次数 +1
3. 新增/编辑习惯、频率、图标颜色
4. 计时型习惯接入专注页与 Session
5. 设置页：三个提醒时段
6. 汇总通知 + AlarmManager + BootReceiver
7. 习惯详情：热力图、连续天数、完成率
8. 数据页习惯区块
9. 单元测试与真机后台验证

---

## 13. 默认选择（可调整）

- 次数型单位默认「次」，可改为「杯 / 组 / 页」
- 次数型步进固定 +1
- 跳过习惯保留连续天数
- 手动完成标记来源，不伪造专注时长
- 删除习惯保留历史
- 习惯计时不计番茄颗数
- 习惯提醒每个时段每天最多一条
- 提醒时段默认 08:30 / 14:00 / 20:30
